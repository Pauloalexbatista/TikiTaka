# ⚽ Tiki-Taka Manager Simulator

Simulador tático e estratégico de gestão de futebol com regras de plantel profissional, mercado de transferências dinâmico, gestão financeira, motor de jogo realista com comentários minuto-a-minuto e sistema de Campeonatos e Ligas com partilha direta por WhatsApp.

## 🚀 Como Iniciar

### Localmente (Node.js)
`ash
npm install
npm start
`
Abre o browser em http://localhost:3000.

### Localmente (Ficheiro direto)
Basta abrir public/index.html diretamente no browser ou executar JOGAR_SIMULADOR.bat.

### Docker / Coolify
`ash
docker build -t tikitaka .
docker run -p 3000:3000 tikitaka
`
